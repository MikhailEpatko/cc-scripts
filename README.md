# cc-scripts

Скрипты и лайфхаки для работы с [Claude Code](https://claude.com/claude-code): обновление, установка вспомогательных инструментов и решения проблем, которые попадались на практике.

## Содержимое

### Скрипты

| Папка | Что делает |
|---|---|
| [`update-cc/`](update-cc/README.md) | Обновляет нативную сборку Claude Code через VPN-прокси. Докачивает при обрывах, проверяет SHA-256 и устанавливает |

### Лайфхаки

| Заметка | О чём |
|---|---|
| [`lifehacks/glab.md`](lifehacks/glab.md) | Как поставить `glab` (GitLab CLI) через `go install`, если Homebrew на Intel-маке собирает его из исходников, и авторизоваться в GitLab |

## Как устроен репозиторий

- Каждый скрипт лежит в своей папке вместе с `README.md`: что делает, что нужно на хосте, как запускать.
- `lifehacks/` — короткие заметки, по одной на тему.
- Скрипты рассчитаны на macOS и Linux.
