# update-cc — обновление нативной сборки Claude Code

Скрипт `update-claude.sh` обновляет нативную сборку Claude Code там, где `claude update` не справляется: сеть нестабильна, рвётся на больших файлах или Anthropic доступен только через VPN.

Что делает скрипт:

1. Узнаёт актуальную версию в вашем канале обновлений (`autoUpdatesChannel`, по умолчанию `stable`) и сравнивает её с установленной.
2. Скачивает бинарник через VPN-прокси `127.0.0.1:10808`. Если связь обрывается, докачивает с того же места.
3. Сверяет SHA-256 с манифестом релиза, проверяет, что бинарник запускается, и устанавливает его.

## Что нужно на хосте

| Что | Зачем |
|---|---|
| macOS или Linux (x64 / arm64, в том числе musl) | На других ОС скрипт сразу завершится с ошибкой |
| `bash`, `curl`, `jq` | Без `curl` и `jq` скрипт не запустится |
| `sha256sum` или `shasum` | Проверка контрольной суммы; одна из утилит есть в системе по умолчанию |
| Нативная установка Claude Code | Лаунчер `~/.local/bin/claude`. Без него скрипт поставит Claude с нуля |
| VPN с HTTP-прокси на `127.0.0.1:10808` | Не обязателен: если прокси не отвечает, скрипт идёт напрямую |

## Запуск

```bash
./update-claude.sh
```

Параметров нет. Если версия в канале не новее установленной, скрипт пишет «Обновление не требуется» и завершается с кодом 0. После обновления перезапустите открытые сессии Claude: они продолжают работать на старой версии.

Скрипт можно запускать из cron или launchd: он ничего не спрашивает, а при ошибке завершается с ненулевым кодом.

## Настройка

- **Канал обновлений** берётся из `~/.claude/settings.json`, ключ `autoUpdatesChannel`. Допустимы `stable` и `latest`, любое другое значение считается `stable`.
- **Адрес прокси** и **порог зависания** заданы константами в начале скрипта: `PROXY` и `MAX_STALLED_ATTEMPTS`. Чтобы их изменить, отредактируйте скрипт.

## Особенности

- **Докачка.** Файл качается в `~/.claude/downloads/claude-<версия>-<платформа>.part` через `curl -C -`. Если соединение 30 секунд держится ниже 1 КБ/с, скрипт его разрывает и начинает новую попытку.
- **Повторы без лимита, пока загрузка идёт.** Пока каждая попытка скачивает хоть что-то, скрипт пробует снова. Он сдаётся только после 20 попыток подряд без прогресса, с нарастающей паузой до 30 секунд. При следующем запуске загрузка продолжится с того же места.
- **Проверка целостности.** Если SHA-256 не совпал, скрипт один раз скачивает файл заново с нуля. Если не совпало и во второй раз, он завершается с ошибкой. Перед установкой скрипт проверяет, что `<бинарник> --version` сообщает ожидаемую версию.
- **Защита от битой установки.** Неудачный `claude update` может оставить пустой или битый файл в `~/.local/share/claude/versions/<версия>`. Скрипт заменяет его проверенным бинарником, причём атомарно: сначала копирует во временный файл, потом делает `mv`.
- **Установка.** Скрипт запускает штатный `claude install <канал>` с переменными прокси. Если после этого лаунчер указывает не на новую версию, скрипт сам переключает симлинк `~/.local/bin/claude`.
- **Платформа.** Определяется автоматически. Если терминал на Apple Silicon работает под Rosetta, скрипт всё равно качает нативный arm64.
- **Нет отката на старую версию.** Если установленная версия новее, чем в канале (например, после переключения с `latest` на `stable`), скрипт ничего не делает.
- После успешной установки скачанный файл из `~/.claude/downloads` удаляется.

## Используемые пути

| Путь | Назначение |
|---|---|
| `~/.claude/settings.json` | Отсюда читается канал обновлений |
| `~/.claude/downloads/` | Загрузки и недокачанные `.part` |
| `~/.local/share/claude/versions/<версия>` | Установленные версии |
| `~/.local/bin/claude` | Лаунчер (симлинк на текущую версию) |

## Частые ошибки

- **`прокси ... недоступен — пробую напрямую`.** Это предупреждение, а не ошибка: VPN не поднят. Если без VPN Anthropic недоступен, поднимите VPN и запустите скрипт ещё раз.
- **`загрузка не продвигается 20 попыток подряд`.** Связь пропала совсем. Восстановите её и запустите скрипт ещё раз: уже скачанная часть сохранится.
- **`в манифесте нет платформы ...`.** Для вашей ОС и архитектуры в этом релизе нет сборки.
- **`после установки ... сообщает версию ...`.** Лаунчер `~/.local/bin/claude` не запускается или указывает не туда. Проверьте его: `ls -l ~/.local/bin/claude`.
- **Скрипт отработал, а `claude --version` показывает старую версию.** В `PATH` раньше `~/.local/bin` стоит другой `claude`, например из npm или Homebrew. Проверьте: `which -a claude`.
