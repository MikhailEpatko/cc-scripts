# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## О проекте

Личная коллекция полезных скриптов и лайфхаков для работы с Claude Code. Сборки, тестов и зависимостей нет: это bash-скрипты и заметки в Markdown. Вся документация, комментарии и сообщения скриптов пишутся на русском.

## Структура

- Каждый скрипт лежит в своей папке (например `update-cc/`) вместе с `README.md`, где кратко описано, что он делает и как его запускать.
- `lifehacks/` — короткие заметки в свободной форме (один `.md` на тему): как поставить и настроить вспомогательные инструменты.

## Соглашения для bash-скриптов (по образцу `update-cc/update-claude.sh`)

- `#!/usr/bin/env bash` и `set -euo pipefail`.
- Вывод через хелперы `log` / `warn` / `die` (цветной префикс, `warn` и `die` пишут в stderr).
- Внешние зависимости (`curl`, `jq`) проверяются в начале через `command -v`.
- Скрипт должен работать и на macOS, и на Linux: учитывать BSD- и GNU-различия (`stat -f %z` / `stat -c %s`, `shasum -a 256` / `sha256sum`), а также Rosetta и musl при определении платформы.
- Сеть идёт через VPN-прокси `http://127.0.0.1:10808`. Если прокси недоступен, скрипт не падает, а идёт напрямую.

## Проверка

Скрипты проверяются запуском, например `./update-cc/update-claude.sh`. Учти, что `update-claude.sh` действительно ставит новую версию Claude Code в `~/.local/share/claude/versions` и переключает `~/.local/bin/claude`. Для синтаксической проверки без запуска используй `bash -n <script>`.
